# 🎨 Cómo Colocar el Icono de la Aplicación

Para colocar tu nuevo icono para **Fruta Clear 3D**:

1. Guarda tu imagen de icono en esta misma carpeta (`resources/`) con el nombre:
   ```text
   resources/icon.png
   ```
   *(Recomendado: imagen cuadrada en formato PNG, idealmente de 512x512 o 1024x1024 píxeles).*

2. También puedes colocar una copia en:
   ```text
   public/favicon.png
   ```
   *(Para que se vea como icono web en el navegador).*

3. Una vez colocada la imagen en `resources/icon.png`, avísame y yo me encargaré de generar y actualizar automáticamente todas las resoluciones nativas de Android (`mipmap-hdpi`, `mipmap-mdpi`, `mipmap-xhdpi`, `mipmap-xxhdpi`, `mipmap-xxxhdpi`).
